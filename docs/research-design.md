# 研究设计

## 研究定位

论文研究五项典型全国碳市场政策首次公开后，A股发电公司的短期异常收益及东方财富股吧讨论变化。

现阶段不估计“碳政策的一般平均影响”，不采用中介效应。核心设计是：

1. 使用事件研究法逐项分析股票反应；
2. 使用文本分析法度量同一政策前后的股吧关注度和不确定性表达；
3. 用帖子内容解释投资者关注的成本、收益和适用资格；
4. 仅在时间顺序清楚、帖子数量足够时，探索早期讨论对后续非重叠行情的预测关系。

## 核心研究问题

### H1：股价反应

重要全国碳市场政策首次公开附近，样本发电公司的短期累计异常收益偏离零。

采用双侧检验。政策可能提高煤电履约成本，也可能提高符合条件项目的CCER收益，不预设全部电力股同向变化。

### H2：讨论反应

政策公开后，股吧中与该政策相关的用户主帖占全部有效用户主帖的比例上升。

不确定性表达不预设方向。复杂的新条款可能增加疑问，正式稿也可能消除疑问。

### 探索性问题

- 公告后讨论越多，随后绝对异常收益或波动是否越大？
- 股吧净情绪越负，随后CAR是否越低？
- 不确定性或意见分歧越高，随后价格分歧是否更明显？

以上只解释为时序关联或增量预测信息，不解释为因果中介效应。

## 事件研究

### 基准模型

估计窗口为 `[-120, -21]`：

```text
R_i,t = α_i + β_i R_m,t + ε_i,t
AR_i,t = R_i,t - (α̂_i + β̂_i R_m,t)
CAR_i[a,b] = Σ AR_i,t
```

### 事件窗口

- 主窗口：`[0, +1]`
- 补充窗口：`[-1, +1]`、`[0, +3]`
- 提前反应检查：`[-5, -2]`

每项政策单独报告公司数、等权CAR和中位数。五项政策不先合并平均。

### 事前暴露

- 强制市场事件：比较高、低煤电暴露公司；
- 自愿市场事件：比较公告前已披露CCER适用项目的公司与其他发电企业；
- 暴露必须使用事件前已经公开的年报、半年报或项目公告；
- 不得用事后业务变化回填。

### 稳健性

- 市场调整收益；
- 流通市值加权；
- 事件日顺延一个交易日；
- 2024年正式配额方案分别使用2024-10-21和2024-10-16；
- 预先选定的安慰剂日期。

## 股吧文本分析

### 分母

政策关注度的分母是公司—日期层面的全部有效普通用户主帖。关键词命中数据不能作为该分母。

### 标签

- `policy_relevant`：明确涉及该事件的配额、基准、履约、方法学、CCER或绿证；
- `uncertainty`：对适用范围、成本、收益或项目资格提出疑问；
- `sentiment`：正面、负面或中性；
- `topic`：配额成本、履约、CCER资格、绿证等；
- `automated_or_media`：资讯号、媒体账号、公告抓取或自动转载。

先双人试标200至300篇，固定规则后再扩大。供应商情绪标签只能作辅助，不能直接替代论文标签。

## 股吧与股价的连接

### 必做：综合对照

每项政策把以下信息放在同一张表：

- 新增条款；
- 适用企业和事前业务暴露；
- `CAR[0,+1]`；
- 政策关注度变化；
- 不确定性和主要讨论主题；
- 具有代表性的原文。

### 优先探索：公告后至开盘前

对于周末或收盘后公开的政策，统计公告后至下一交易日开盘前的讨论，再观察开盘后的异常收益或波动。

2024-02-04 19:03公开的《碳排放权交易管理暂行条例》适合这一设计。

### 备选：同一政策内部比较

```text
Y_i,e = α_e + μ_i + β Discussion_i,e
        + γ Exposure_i,e + θ X_i,e,pre + ε_i,e
```

- `α_e`：事件固定效应；
- `μ_i`：公司固定效应；
- `Exposure`：煤电或CCER暴露；
- `X_pre`：事前波动、规模、换手率、此前收益和日常股吧活跃度。

讨论窗口必须先于结果窗口。窗口内存在业绩、重组等公司重大公告的观测应剔除。

## 不能作出的结论

- 不能根据五项政策估计全部碳政策的一般平均影响；
- 不能把几十家公司当作几十次独立政策冲击；
- 不能把同一天重叠的发帖和收益解释为讨论导致收益；
- 不能把股吧用户代表为全部投资者；
- 不能在数据不完整时预写显著性结果。
