# 实施流程

## 1. 锁定研究范围

- 固定五项核心政策和一个补充政策；
- 事件研究和股吧文本分析为必做部分；
- 时序关联为可选部分；
- 不采用中介效应。

交付物：研究问题、假设和边界说明。

## 2. 锁定政策台账

- 核对官方标题、链接、落款日和首次公开日；
- 确定股票事件日和替代日期；
- 摘录相对前版的增量条款；
- 检查提前报道和政策重叠。

交付物：`config/events.csv`及事件日期说明。

## 3. 确定公司样本

- 从现有89个代码开始；
- 剔除B股和非发电主营公司；
- 按每个事件发生时的历史状态判断；
- 整理煤电占比和公告前CCER适用项目。

交付物：公司—政策事件样本表和事前暴露表。

## 4. 补导CSMAR行情

按照`data/README.md`补齐个股和市场字段。至少覆盖2022年8月至2024年11月，保留2021至2025年全段亦可。

交付物：本地原始行情文件，不提交Git。

## 5. 清洗行情和公告

- 统一六位股票代码和交易日期；
- 合并个股收益与市场收益；
- 剔除停牌、缺失和估计窗不足的观测；
- 核查业绩、重组、电价和煤价冲击；
- 保存每一项剔除原因。

交付物：可复核的样本筛选表。

## 6. 完成事件研究

- 计算AR和各窗口CAR；
- 逐事件报告，不先平均；
- 完成煤电与CCER暴露分组；
- 完成日期、市场模型和权重稳健性。

交付物：逐事件CAR表、暴露分组表、稳健性表。

## 7. 取得股吧试样

优先选择：

1. 2024年《碳排放权交易管理暂行条例》；
2. 一项CCER方法学或配额政策。

每项政策选择若干论坛活跃度不同的发电公司，索取公告前14日至后7日的全量主帖。

验收：

- 正文完整；
- 首次发布时间精确；
- 证券匹配正确；
- 能识别资讯号；
- 能区分零帖与归档缺失；
- 政策相关帖子数量足够。

## 8. 正式采购并清洗股吧数据

- 采购五项核心事件窗口内的全量主帖；
- HTML转纯文本；
- 帖子ID去重；
- 剔除媒体、资讯号和自动转载；
- 普通无关帖子保留为关注度分母；
- 记录数据覆盖和缺失。

交付物：本地清洗数据，不提交Git。

## 9. 建立文本标注规则

- 政策相关；
- 不确定性表达；
- 正面、负面或中性；
- 讨论主题；
- 自动或媒体内容。

先双人试标，再固定规则。

交付物：标注手册和一致性记录。

## 10. 完成股吧主分析

- 政策帖数；
- 全部有效用户主帖数；
- 政策关注度；
- 不确定性占比与条数；
- 净情绪；
- 意见分歧。

比较公告后第1至3日与公告前同星期日期。

## 11. 连接股吧和股价

按优先级执行：

1. 政策—暴露—CAR—讨论综合对照；
2. 公告后至开盘前讨论与开盘后行情；
3. 同一政策内部控制暴露和事前公司特征的比较。

结论限定为解释性证据或时序关联。

## 12. 完成论文

推荐写作顺序：

1. 第三章研究设计；
2. 第四章数据与变量；
3. 第五章事件研究结果；
4. 第六章文本和综合分析；
5. 第一、二章；
6. 摘要与结论。

最终检查政策日期、样本数、表格数字、窗口口径和参考文献是否一致。
